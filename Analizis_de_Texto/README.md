# Analizis_de_Texto

Analizador de texto por consola escrito en Python. El usuario introduce un texto y el programa calcula estadísticas básicas: total de palabras, palabras que aparecen una sola vez, caracteres especiales, número de oraciones, promedio de palabras por oración, palabra más frecuente, palabra más larga y más corta, y un top 5 de palabras por longitud y por frecuencia. Está pensado para textos en inglés.

## Ejecución

```bash
python analizador.py
```
