# Gestor_de_Estudiantes_CSV

Sistema de gestión de estudiantes por consola que guarda la información en un archivo CSV. Permite registrar alumnos con nombre, edad, carrera y nota, listarlos, buscarlos, actualizar su nota, eliminarlos y consultar estadísticas como promedio, nota máxima y mínima, y aprobados y reprobados. Incluye validación de los datos ingresados.

## Ejecución

```bash
python program.py
```
