# Palabra_aleatoria

Proyecto experimental en Python sobre transformación de palabras y recursión. El script, ubicado en `palabra aleatoria/palabra-aleatoria.py`, contiene una idea comentada que reemplaza cada letra por una letra aleatoria y una pequeña demostración de llamadas recursivas entre funciones. Actualmente es un borrador de práctica, no una aplicación terminada.

## Ejecución

```bash
python "palabra aleatoria/palabra-aleatoria.py"
```
