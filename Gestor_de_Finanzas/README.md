# Gestor_de_Finanzas

Gestor de finanzas personales por consola. Permite registrar ingresos y gastos con categoría, monto y fecha automática, guardar todo en un archivo `data.json` para conservarlo entre sesiones, consultar el balance total y ver el historial detallado de ingresos y gastos. Es un proyecto sencillo para practicar JSON, fechas y menús interactivos en Python.

## Ejecución

```bash
python gestor_de_finanzas.py
```
