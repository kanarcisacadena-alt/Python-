# Buscador_de_Libros_y_Autores

Buscador de libros y autores por consola. Usa la API pública de Open Library para consultar por título o autor y muestra hasta cinco resultados con autor, título, año de primera publicación e idioma. Permite repetir búsquedas hasta que el usuario decida salir. Requiere conexión a internet y la librería `requests`.

## Ejecución

```bash
pip install requests
python explorer.py
```
